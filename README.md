# Device KPI Dashboard

A Streamlit dashboard for monitoring electronic measurement devices in a DevOps/build engineering environment.

## Features
- KPI monitoring for device status, test pass rate and pipeline success
- Detection of problematic devices
- Interactive filters
- Visualizations for status, test results and test duration

## Tech Stack
Python, Pandas, Streamlit, Plotly

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
